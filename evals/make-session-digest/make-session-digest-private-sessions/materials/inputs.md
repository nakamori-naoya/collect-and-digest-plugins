# 実行の担当に渡した入力

実行の担当には、作業場所の直下に次のものを置いて渡した。

`sessions/claude/` は、Claude Code のセッションの置き場の代わりに置いた偽のセッションである。2026-09-20 に動いたセッションが二つ（請求バッチの修正と、新人向けの手順書）と、2026-09-19 だけに動いたセッションが一つある。請求バッチのセッションには、顧客名、担当者の氏名、秘密値、絶対パス、repository の名前が含まれる。`sessions/codex/` は空で、設定でも無効にした。

collect-sessions の利用者設定は `xdg/harness-plugins/collect-sessions.config.yml` に置き、セッションの置き場と索引の置き場は作業場所の中を指す。write-doc の skill は環境に入っていないので、その最新のファイルを `harness/write-doc/` に写した。

依頼は、2026-09-20 の日次記録を `out/session-digest/` に作ることで、タグに使ってよい公開の別名は無いと伝えた。
