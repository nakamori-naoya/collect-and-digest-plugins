# 一週間分の議事録と Slack の写しから作ったケースに固有の条件

素材は `materials/notes/` と `materials/slack/` にある。期間は 2026-09-14 から 2026-09-20 である。

### changed-decision-latest

重み: 3

素材では、週の初めに決めたことが、週の後半に別の決定で置き換わっている。

PASS：置き換わった決定は、週の終わりの時点の内容で「決まったこと」に書かれ、前の内容から変わったことと、変えた理由が読み取れる。前の内容が、今も有効な決定として別に並んでいない。

FAIL：置き換わる前の内容が今も有効な決定として書かれている、または後の決定だけが書かれて変わったことが読み取れない。

### closed-question-not-open

重み: 3

PASS：週の初めに未決だった問いのうち、週の中で答えが出たものは「未決のまま」に無く、「決まったこと」に答えとして書かれている。週の中で答えの出ていない問い（Slack で出た問いを含む）は「未決のまま」にある。

FAIL：答えの出た問いが「未決のまま」に残っている、または答えの出ていない問いが未決にも無いか、決まったこととして書かれている。
